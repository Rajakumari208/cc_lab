Experiment 8: Build and Run First Docker Container
Aim: Write a Dockerfile, build a custom python image, and run it locally.

Dockerfile:
FROM python:3.9-slim
WORKDIR /app
COPY main.py .
CMD ["python", "main.py"]

main.py:
print("Hello from inside the Docker Container!")
print("Docker is fully functional!")
